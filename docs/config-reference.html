Reference

config.yml reference

parts changing soon

Every key of plugins/MythicMobs/AIConfig/config.yml with its type, shipped default and accepted range, read from the plugin's own sources.

The master file lives at plugins/MythicMobs/AIConfig/config.yml. ThePredict creates it on the first start and never overwrites it. Every value in the shipped file is the default, and units are in the key names (Millis, Ticks, Blocks, Micros).

Watch out Read once, at startup

config.yml and the Jev key are read only when the server starts. After a change, restart the server. /mm reload re-reads the profiles, not this file. An unknown key, a key from the old schema or a value out of range keeps ThePredict inactive and names the file, the path and the reason; MythicMobs keeps working.

How to read the entries below: Default is the value in the shipped file, Range comes from the plugin's validation, and keys a profile can override link to the Profile reference. Keys marked changing soon will be redefined in an upcoming release; keys marked no effect yet are accepted and validated but this build does not read them, and most of them log AIConfig/config.yml: <key>: has no effect in this build at startup when set to anything other than the shipped value.

Note Sections not covered here

The shipped file also holds a few sections for experimental features that stay off or record-only by default. They are not covered by this documentation: leave them as shipped.

Schema of the file. Required, and only 2 is accepted. A file without it that holds schema 1 keys (such as provider) is treated as an old configuration: ThePredict loads nothing from it and writes a migration proposal instead.

#jev

Type
URL
Default

TypeSafe Jev endpoint. https is required; plain http is accepted only for a loopback host (localhost, 127.0.0.1 or ::1). No user, query or fragment.

Type
text
Default
jev-1.13.0

Versioned Jev model ID, 1 to 64 letters, digits, ., _ or -. Only jev-1.13.0 is tested with this release. If a key is pasted here by mistake, the file is refused at load without showing the value.

text

Name of the environment variable that holds the key (an empty value means only jev.apiKey is used). The variable wins over jev.apiKey when both are set. Write the variable's name here, never the key itself.

Key stored in the file. Leave it empty and use the environment variable instead whenever you can. ThePredict never prints it: not in the console, not in /thepredict status, not in migration reports.
