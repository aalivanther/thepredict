Combat systems

Difficulty

parts changing soon

How hard a ThePredict mob plays today: presets that set a target fight length, a pressure controller, reaction floors and the opt-in Entropy mode.

Changing soon This whole page will change

In an upcoming release, difficulty becomes a level of intelligence and aggression (Fácil, Normal, Difícil, Entropía, Absolute Void) instead of a target fight length, and the "fair player" rules around it will be redefined. This page documents how the current build works, so you can use it today.

#Presets

Today a preset sets the target length of a whole fight against players, plus how quickly the mob may react to them. Against other entities the mob simply plays at full power.

Mob file nameconfig.yml keyTarget fight lengthReaction floor (ticks)Entropy floor (ticks)Entropy start
Fácilfacil45 min547 s
Normalnormal30 min535 s
Difícildificil15 min303.5 s
Caoscaos10 min101.5 s
Vacíovacio5 min000 s

Choosing a preset:

  • Per mob, in the MythicMobs mob file (with Predictor: true): PredictorDifficulty, one of Fácil, Normal, Difícil, Caos, Vacío (case and accents ignored). Without it, difficulty.defaultPreset applies (normal). Another value is a catalog error: <Mob>.PredictorDifficulty: must be one of Fácil, Normal, Difícil, Caos, Vacío, and the mob stays unbound.
  • Per world, by the administrator: difficulty.worlds.<world>.preset and .entropy in config.yml beat the mob file.
  • Players never choose the difficulty.
Mob fileYAML
MyBoss:
  Type: WITHER_SKELETON
  Predictor: true
  PredictorDifficulty: Difícil
  PredictorEntropy: false
config.ymlYAML
difficulty:
  worlds:
    arena_nether:
      preset: dificil
      entropy: false

The numbers of each preset live under difficulty.presets.<name> (see the config.yml reference).

#Modes

difficulty.defaultMode (or a profile's Difficulty.Mode) decides how a mob picks its pressure:

ModeBehavior
auto (default)player against players, bench against everything else.
playerA controller aims the whole fight at the preset's target length.
benchFull power, fixed rung, no controller.

#Pressure

The controller moves a pressure rung from 0 (gentlest) to 8 (full power). Each rung sets how quickly the mob may react, how eagerly it fires damage, and how much it may exploit enemy patterns:

Rung012345678
Reaction delay (ticks)20181614121086the preset's floor
Share of casts that may exploit a pattern0000.100.200.300.400.500.50

Against players the reaction delay never goes below the preset's reaction floor (reactionFloorTicks); against entities the floor is 0. A profile's Timing.ReactionDelay can only raise it. Higher rungs also prefer damaging skills and give damaging casts less slack; in a group, lower rungs allow fewer melee attackers at once and wider gaps between impacts.

How the rung moves:

  • In the fight, every difficulty.adjustIntervalTicks, the controller projects how long the fight will last from the damage dealt so far. Outside the difficulty.toleranceRatio band around the target it moves the rung (a profile can turn this off with Difficulty.InFight). Estimates count only after difficulty.minEvidenceTicks; a fight closes after difficulty.disengageTicks without the mob dealing damage.
  • Between fights, the starting rung learns from how fights ended (difficulty.learningGain, difficulty.deadbandRatio, difficulty.dampingReversals); a profile can turn this off with Difficulty.Learn or fix the start with Difficulty.StartRung.
  • A profile can bound the rung with Difficulty.MinRung and Difficulty.MaxRung, and set its own target with Difficulty.TargetSeconds (5 to 3600 seconds).

<caster.predictor.pressure> shows the rung while the controller plays (none otherwise).

Note No effect in this build

The profile key Difficulty.Tolerance is accepted, but the controller always uses difficulty.toleranceRatio. difficulty.maxTrackedFights is accepted but not read. Unlike other keys without effect, these two log no warning.

#Entropy

PredictorEntropy: true (with Predictor: true) turns on an opt-in lethal mode, against players:

  • The mob always plays at the highest rung, without the controller, and no stat is ever changed.
  • Its reaction delay starts at the preset's reaction floor and shrinks in a straight line over the target time down to entropyReactionFloorTicks; its adaptation time (how long before it asks again or replans) starts at entropyAdaptStartSeconds and shrinks toward zero.
  • Tell minimums do not apply, feints use Telegraph.EntropyCommitment, and the group's fairness limits only record.
  • It never reads hidden player input.

An administrator can force Entropy on or off per world with difficulty.worlds.<world>.entropy. A value other than true or false in the mob file is a catalog error: <Mob>.PredictorEntropy: must be true or false.

#MythicMobs level

With difficulty.nativeLevelAllowed true, a profile with Difficulty.NativeLevel spawn lets five fights in a row at an extreme move the MythicMobs level of the next spawn by ±1, within the mob's level ±2. Never during a fight.

#Checking difficulty in game

CommandWhat it does
/thepredict eval statusThe difficulty block of the nearest bound mob (for a player), or the default preset at full power.
/thepredict eval difficulty <nearest|uuid>The block of one mob: preset <name> entropy <true|false>, then r <reaction ticks> c <adaptation seconds> pressure <rung|bench>.
/thepredict eval pressure <nearest|uuid> <0-8|auto>Pins a mob's rung for testing; auto releases it. Not stored. Also needs thepredict.debug.
/thepredict eval verdict list / verdict import <file>Lists or imports evaluation verdicts, which unlock modes that wait for one (such as pattern bias).
/thepredict eval reportNot available on the server in this release.

All of them need thepredict.eval (operators by default). See Commands & permissions.
