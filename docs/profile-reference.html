Profile reference

parts changing soon

Every key of a ThePredict profile, plus the keys ThePredict reads from the MythicMobs mob file, with type, default and range.

A profile file is a .yml or .yaml file in plugins/MythicMobs/AIConfig/Profiles/ that starts with schemaVersion: 2 and holds one or more profiles. Each profile is keyed by its ID (snake_case is recommended). For the concepts behind these keys, start with Profiles, tactics & contexts.

Tip Strict by design

An unknown key is an error that names the file and the path (is not a known field), and a profile with an error is skipped while the others keep loading. Values a profile does not set come from profileDefaults in config.yml, and no profile can widen the global decision.* limits.

Note off and on need no quotes

YAML reads a bare off or on as a boolean; every mode key of a profile reads it back as off or on, so Native: off and Native: "off" mean the same.

Note Keys with no effect yet

A few keys are accepted and validated but not used by this build. They are marked no effect yet below; when a profile gives one of them a value other than its default, the profile still loads and the console logs <file>: <profile>.<path>: has no effect in this build.

A profile that uses most sections
AIConfig/Profiles/guardian_full.ymlYAML
schemaVersion: 2
guardian_full:
  MythicID: ThePredictGuardian
  TypeOfMythicID: MOB
  Type: NORMAL
  Objective: Protect the altar and punish players who attack it from range
  Choices:
    melee: { MythicID: ThePredictGuardianMelee, TypeOfMythicID: SKILL, RequiresTarget: true }
    ranged: { MythicID: ThePredictGuardianRanged }
    defense: { MythicID: ThePredictGuardianDefense, RequiresTarget: false }
    punch: { Kind: VANILLA_MELEE }
  Tactics:
    press_and_strike: { Movement: APPROACH, Choice: melee, Priority: 70 }
    brawl: { Movement: APPROACH, Choice: punch, Priority: 40 }
    keep_distance_and_shoot:
      Movement: KEEP_DISTANCE
      Choice: ranged
      Description: Stay outside melee reach and shoot while the target approaches
      Priority: 60
    retreat_and_defend: { Movement: RETREAT, Choice: defense, Priority: 90 }
    flank_and_strike: { Movement: FLANK, Choice: melee }
    hold: { Movement: HOLD, Description: Wait for the target to come closer, Priority: 10 }
  Contexts:
    wounded:
      Conditions:
      - healthpercent{p=<30%}
      Priority: 95
      Tactics: [retreat_and_defend, keep_distance_and_shoot]
    idle:
      Priority: 10
      Tactics: [hold]
      DirectTactic: hold
  Movement:
    MeleeReach: 2.5
    RangedReach: 16
    Band: { Inner: 5, Outer: 9 }
    Retreat: { Distance: 10, Speed: 1.2 }
    Approach: { Speed: 1.15 }
    Arena: { Radius: 24 }
  Health: { Critical: 0.3, Wounded: 0.6 }
  Threat: { AssistsOthers: 1.5, RangedHarass: 1.0, BlockedHits: 0.25, UnreachableDecayPerSecond: 2.0, MaxPerWindow: 20.0 }
  BaseAI:
  - 1 meleeAttack
  - 2 randomStroll
  Timing: { MinimumConfidence: 0.45, SwitchMargin: 0.15, QuestionDetail: full, FitChecks: false, CastMode: any_ready, ReadyHorizon: 0 }
  Participants:
    PlayerGameModes: [SURVIVAL, ADVENTURE]
    Entities:
      Allow: ['kind:MONSTER', 'faction:altar_raiders']
      Deny: ['category:ANIMAL']
      PerceiveNonTargets: false

#Mob file keys

These keys go in the MythicMobs mob file (plugins/MythicMobs/Mobs/*.yml), next to Type and Health, not in the profile. A wrong value is a catalog error that names the mob, and the mob stays unbound.

plugins/MythicMobs/Mobs/MyBoss.ymlYAML
MyBoss:
  Type: ZOMBIE
  Health: 200
  Predictor: true
  PredictorDifficulty: Difícil
  PredictorEntropy: false
Predictor
Type
boolean
Default
false

In the MythicMobs mob file. Turns ThePredict on for this mob. The mob also needs a valid profile whose MythicID names it. Any value other than true or false is a catalog error (<Mob>.Predictor: must be true or false). With false, or without the key, the mob is a plain MythicMobs mob.

PredictorTraining
Type
boolean
Default
false

In the mob file. With true (and Predictor: true), this mob may also explore other tactics against players, to collect learning data (see Learning & training). Players do not see it. Remove the key to turn it off; there is no command or global switch. PredictorTraining: true without Predictor: true is a catalog error.

PredictorDifficultychanging soon
Type
text
Values
Fácil, Normal, Difícil, Caos, Vacío (case and accents ignored: facil and Dificil work)
Default
difficulty.defaultPreset (normal)

In the mob file, with Predictor: true. Difficulty preset of this mob: the target length of a whole fight against players. Another value is a catalog error and the mob stays unbound. See Difficulty.

PredictorEntropychanging soon
Type
boolean
Default
false

In the mob file, with Predictor: true. Opt-in lethal mode: the mob always plays at full pressure and its reaction, adaptation and replanning times shrink during the fight down to the preset's floor. It never reads hidden player input. See Difficulty.

#Choices

Choices.<id> — one entry per skill (or vanilla hit) the tactics can use. The ID is yours: [a-z][a-z0-9_]{0,39}, local to the profile, never sent to Jev.

Choices.<id>.Kind
Type
text
Values
MYTHIC_SKILL, VANILLA_MELEE
Default
MYTHIC_SKILL
MYTHIC_SKILL casts a MythicMobs skill. VANILLA_MELEE deals a vanilla hit (never farther than Movement.MeleeReach, at most one hit every 20 ticks, like vanilla) and takes no MythicID.
Choices.<id>.MythicID
Type
text
Required
with MYTHIC_SKILL

Exact MythicMobs skill ID (case-sensitive). The skill should declare an Intention line (see Skills & intents). Must be absent for VANILLA_MELEE.

Choices.<id>.TypeOfMythicID
Type
text
Values
SKILL

Kept for compatibility. Only SKILL.

Choices.<id>.RequiresTarget
Type
boolean
Default
true

Whether the choice needs a target. A self-heal or a self-buff is usually false.

Choices.<id>.CD
Type
integer
Default
0
Range
0 or more
Unit
ticks

Extra cooldown per mob, for compatibility only. Prefer the skill's native Cooldown (and Charges), which ThePredict reads and respects.

Choices.<id>.Purpose
Type
section
Administrator override, not for authors. A full typed purpose that replaces the skill's Intention line for this choice (the binder warns Choices.<id>.Purpose overrides the Intention of skill '<S>'). It is the only form that takes numbers (Reach, Radius, WindUp). See Skills & intents.
Choices.<id>.Telegraphchanging soon
Type
section

Overrides what ThePredict deduces about this skill's tell: Danger, Answer and RecoveryTicks.

Choices.<id>.Displacement
Type
text
Values
NONE, KNOCKBACK, STRONG_PUSH, PULL, SELF_FORWARD, SELF_BACKWARD, SELF_OTHER

Overrides how ThePredict reads the skill's push (it reads damage knockback, throw, leap, explosions and pulls). A skill with nested skills, projectiles or auras is assumed to KNOCKBACK; set Displacement: NONE if it does not push.

Choices.<id>.TargetsAllies
Type
boolean

Overrides whether ThePredict thinks the skill can reach allies (it reads targeters such as @MobsInRadius, @Parent or @Children). Matters for the SUPPORT group role.

#Tactics

Tactics.<id> — 1 to 255 tactics. The ID is the option name Jev reads: [a-z][a-z0-9_]{2,39} (3 to 40 characters, starting with a letter). none and the prefixes debug_, tell_ and stance_ are reserved.

Tactics.<id>.Movement
Type
text
Values
APPROACH, KEEP_DISTANCE, RETREAT, HOLD, FLANK, NONE
Required
yes

How the mob moves while the tactic runs (see Movement & goals). FLANK requires a Choice. Species with a Brain only accept NONE.

Tactics.<id>.Choice
Type
text

ID of the choice this tactic casts. A tactic without a choice only moves.

Tactics.<id>.Description
Type
text

What the tactic does, in English, for Jev. With standard and full detail it is sent whole; with compact only an excerpt is used, when needed to tell two options apart. Put the essential first.

Tactics.<id>.Priority
Type
integer
Default
50
Range
0 – 100

Order of the local planner: among the eligible tactics, the highest priority wins. Also decides which options are kept when a question is over the option cap.

Tactics.<id>.Stance
Type
text
Values
NEUTRAL, PRESSING, GUARDED, EVASIVE

Base stance while this tactic runs, instead of the one Stances.ByMovement gives its movement.

#Contexts

Contexts.<id> — up to 16 contexts. The ID follows the choice ID rules. idle, attacking_phase, tracking_enemy and low_health_phase are shortcut contexts computed by ThePredict and take no Conditions (see Profiles, tactics & contexts).

Contexts.<id>.Conditions
Type
list
Required
except in shortcut contexts

MythicMobs condition lines, at least one; all must hold. Only entity conditions work here (they are evaluated on the mob itself, outside any skill). Not allowed in the shortcut contexts idle, attacking_phase, tracking_enemy and low_health_phase.

YAML
Conditions:
- healthpercent{p=<30%}
Contexts.<id>.Priority
Type
integer
Default
50
Range
0 – 100

When several contexts are active, the highest priority decides. With equal priorities, the one declared first wins and the catalog warns.

Contexts.<id>.Tactics
Type
list
Required
yes

Tactics eligible while this context is active, at least one, no repeats.

Contexts.<id>.DirectTactic
Type
text

Optional. Must be listed in Tactics. In local mode this tactic is picked directly while the context is active.
